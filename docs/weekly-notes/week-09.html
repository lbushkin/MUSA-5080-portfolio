Week 9: Introduction to Predictive Policing

Poisson Modeling and Predicting Crime
Published

October 30, 2026

What We Did

Learned about Poisson models and how they relate to predictive policing models.

Key Concepts

Introducing Poisson

  • Used for non-linear relationships, specifically right-skew distribution with a lower bound of zero
  • Coefficient is the multiplicative change in expected count per one-unit change in x
    • Ex: Each one-unit increase in x means 22% more expected burglaries
  • Poisson models assume that the variance = mean
    • If the variance is much bigger than the mean: “overdispersion”
    • I.e. if data is “really” skewed, might need to use a negative binomial model instead
  • Code: glm(model, family = “poisson”, data = “dataset”)
    • To see predictions per observation: mutate(pred_poisson = predict(poisson, type = “response”))

Predictive Policing

  • The original idea was to take human bias out of police decision-making, arguing that it would be “more objective”
    • Could be place-based (i.e. certain neighborhoods) or person-based (i.e. identifying “risky” individuals)
  • “Dirty data”: data that is biased, incomplete, or manipulated
    • Not all crimes are reported, and we know that those that are, are influenced by racial and class prejudices
    • Leads to a confirmation feedback loop
    • Ex: Chicago heat list
    • These models end up predicting and reinforcing police activity, not predicting the actual behavior of residents
  • Broken windows theory: lack of maintenance can reflect precursor for criminal behavior
    • No longer accepted, because it punishes individuals for perceived disorderly behavior
    • I.e. profiling

Example of a predictive policing model: burglaries in Philadelphia

  • Using 2024 data to predict 2025 burglaries
  • Will divide Philadelphia into 500 sq ft cells (relatively high resolution)
    • Code: st_make_grid(philly, cellsize = 500, square = TRUE)
  • Possible variables: street lighting, graffiti, 311 calls, litter score, proximity to police stations

Model Evolutions

  • Kernel density map: smoothing out points to create a map of hot spots, essentially
  • Risk terrain: uses logistic regression
  • ML: uses random forest and neural nets
  • Person based: uses network analysis
